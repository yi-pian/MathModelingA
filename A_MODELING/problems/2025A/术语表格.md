# 2025 A 题术语表

## 核心概念

| 中文 | English | 符号/缩写 | 定义 |
|---|---|---|---|
| 烟幕干扰弹 | smoke-screen munition | SSM | 投放后作抛体运动并在预定时刻起爆的弹体 |
| 烟幕云团 | smoke cloud | C | 起爆后形成、以 3 m/s 下沉的有效球形区域 |
| 有效遮蔽 | effective obscuration | EO | 选定几何判据满足且处于云团有效期内 |
| 代表点视线模型 | representative-point line-of-sight model | Model A | 只检验导弹到圆柱几何中心的视线 |
| 完整圆柱遮蔽模型 | full-cylinder occlusion model | Model B | 检验导弹到圆柱全部边界点的视线 |
| 遮蔽区间 | obscuration interval | I | 连续时间轴上事件成立的闭区间 |
| 区间并集时长 | union duration | L | 合并重叠区间后的总测度 |
| 边际遮蔽增益 | marginal coverage gain | ΔL | 新增一枚烟幕弹后并集时长的增加量 |

## 数学符号与单位

| 符号 | 含义 | 类型 | 单位 |
|---|---|---|---|
| `t` | 雷达发现后的统一时间 | state | s |
| `theta_i` | 无人机 FYi 的水平航向角 | decision | rad（Excel 为 degree） |
| `v_i` | 无人机 FYi 飞行速度 | decision | m/s |
| `t_d` | 投放时刻 | decision | s |
| `tau` | 投放至起爆的延时 | decision | s |
| `t_e` | 起爆时刻，`t_d+tau` | state | s |
| `p_M(t)` | 导弹位置 | state | m |
| `p_FY(t)` | 无人机位置 | state | m |
| `p_B(t)` | 弹体位置 | state | m |
| `p_E` | 起爆点 | output | m |
| `p_C(t)` | 云团中心 | state | m |
| `D(t,q)` | 云团中心到导弹—目标点闭线段的距离 | state | m |
| `g_A,g_B` | 遮蔽有向事件函数 | state | m² |
| `R_C` | 云团有效半径 | parameter | m |
| `T_C` | 云团有效寿命 | parameter | s |
| `L_j` | 对导弹 Mj 的总遮蔽时长 | output | s |

## 算法术语

| 中文 | English | 说明 |
|---|---|---|
| 粗定位—精确求根 | coarse localization and refined root finding | 采样只找事件区间，Brent 法确定端点 |
| 切触事件 | tangential event | 事件函数接触 0 但不变号 |
| 有序时间参数化 | ordered-time parameterization | 从非负间隔构造投放时刻，直接满足顺序约束 |
| 多起点优化 | multi-start optimization | 多 seed/初值产生候选并高精度复算 |
| 候选策略池 | candidate strategy pool | 离散指派前保存各无人机—导弹的可行连续策略 |
| 束搜索 | beam search | 只保留上界/目标较优的有限组合状态 |
| 表面采样收敛 | surface-sampling convergence | 加密圆柱边界采样并比较事件端点和时长 |

同一概念在代码、图、Excel 验收和报告中必须沿用本表命名；距离与距离平方分别使用 `distance_m` 与 `distance_sq_m2`。
