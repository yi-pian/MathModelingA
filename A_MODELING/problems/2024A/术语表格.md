# 2024A 术语与符号表

| 中文术语 | 英文术语 | 符号 | 定义/单位 |
|---|---|---|---|
| 等距螺线/阿基米德螺线 | Archimedean spiral | \(r=a\theta\) | 相邻圈径向间距恒为 p |
| 螺距 | pitch | p | m |
| 螺线参数角 | spiral parameter | \(\theta\) | rad |
| 弧长坐标 | arc-length coordinate | s | m |
| 把手节点 | handle node | \(\mathbf h_i\) | 孔中心的全局坐标，m |
| 孔中心距 | handle-center distance | \(L_i\) | 2.86 m 或 1.65 m |
| 运动切向量 | motion tangent | \(\mathbf t_i\) | 沿实际行进方向的单位向量 |
| 速率 | speed | \(u_i\) | m/s，非负标量 |
| 定向矩形 | oriented rectangle | \(B_i\) | 板凳在水平面的实际占用区域 |
| 分离轴定理 | separating axis theorem | SAT | 凸多边形相交判定 |
| 有符号间隙 | signed clearance | \(c_{ij}\) | m；正分离、零接触、负相交 |
| 首次碰撞时刻 | first-contact time | \(t_*\) | s |
| 临界螺距 | critical pitch | \(p_*\) | m |
| 调头空间 | turnaround region | - | 半径 4.5 m 的圆 |
| S 形调头曲线 | S-shaped turnaround curve | - | 两段反向弯曲且相切的圆弧 |
| 速度放大倍数 | speed amplification factor | M | 全节点速率/龙头速率的最大值 |
| 求根残差 | root residual | - | 代回方程后的绝对误差 |
| 链式约束误差 | link-constraint error | - | \(|\|h_{i+1}-h_i\|-L_i|\)，m |
