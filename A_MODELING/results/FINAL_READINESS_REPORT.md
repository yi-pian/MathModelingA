# A_MODELING 正式比赛最终毕业评价

综合验收：2018A、2022A、2023A、2024A、2025A  
最终结论：**CONDITIONALLY READY**

A_MODELING 已经是可在 2026 高教社杯 A 题比赛现场直接使用的数值工程工具箱，但不是能替代建模手的自动解题系统。条件不在基础数值库，而在三类必须人工签字的边界：题意/物理定义、题外常数、受限搜索空间与全局最优主张。

## 2. 哪些模块只有单元测试没有整题实战

按模块级别：**没有**。现有 13 个 core 模块都至少在一道完整 A 题中被自然调用。

按 API/分支级别仍有只靠单元测试的部分，例如少见错误分支、个别求解器方法组合和边界输入；“模块经历过实战”不等于每个参数组合都获得比赛级证明。尤其不能据 `core.optimization` 测试通过就推导出任意高维问题已找到全局最优。

## 3. 哪些能力已经至少被两道不同 A 题验证

1. 一维/多维求根、粗定位后精化：2018A、2022A、2024A、2025A。
2. 三维几何和有限对象判定：2023A、2024A、2025A。
3. 连续事件而非固定步长累计：2018A、2024A、2025A。
4. 连续优化＋高精度复算＋邻域扰动：2022A、2024A、2025A。
5. 多精度/网格/步长收敛：五题均有不同形式。
6. 约束残差、守恒或几何接口检查：五题。
7. 官方 Excel 模板复制、回读和语义复算：五题。
8. 论文图与 Origin 数据一致性：五题。
9. 性能按“算法/缓存/向量化/筛选”顺序控制：2022A、2023A、2024A、2025A。
10. 在模型不能由代码决定时主动标记 `MODEL_CONFIRMATION_REQUIRED`：2022A、2023A、2025A。

## 4. 哪些能力仍是单点风险

| 能力 | 当前证据 | 风险 |
|---|---|---|
| 耦合 ODE/周期射击 | 仅 2022A | 新题若含刚性、冲击、事件切换或 DAE，现证据不足 |
| 参数拟合与可辨识性 | 仅 2018A | 多数据源、异方差、强相关或贝叶斯不确定性未实战 |
| 大规模空间索引 | 仅 2023A | 动态点云、非欧式邻域或高维索引未实战 |
| core sensitivity API | 仅 2022A | 2025A 复杂扰动仍用题目专用审查器 |
| 多层 PDE | 仅 2018A 且不在 core | 二维/非线性/移动边界 PDE 未验证 |
| 离散＋连续组合优化 | 仅 2025A | 候选池限制已被外部更优值暴露，仍是最大风险 |
| 自由布局/高维全局最优 | 2023A、2025A 均为条件通过 | 工具箱能给高质量可行解，不能自动给证明 |
| 模糊物理语义 | 2022A、2023A、2025A | 数值正确不能替代建模手选择惯量、太阳模型、遮蔽定义 |

## 5. 最常出现的 10 个错误

1. **把合理假设当题面事实**：纵摇惯量、太阳半角、目标采样权重、遮蔽定义。
2. **把受限参数族内最优写成原问题全局最优**：2023A 布局族、2025A 一机一导弹候选池。
3. **物理方程来源混用**：2022A 初版单体受力与整体拉格朗日质量矩阵混用，曾导致能量缺口。
4. **用终点或固定 dt 代替连续临界事件**：2024A 临界螺距必须看完整过程；2025A 必须定位全部进入/退出根。
5. **把有面积/体积对象偷换成点或无限直线**：板凳中心、镜面中心、圆柱中心、导弹—目标无限直线。
6. **重叠区间直接相加**：多烟幕必须并集，多导弹必须分集合后按题意组合。
7. **优化器状态和边界处理不严**：`success=False`、上下界反转、最大/最小写反、边界最优被误判。
8. **单位、坐标、状态顺序混乱**：degree/rad、mm/m、局部/全局、位置/速度、距离/距离平方。
9. **Excel“保存成功”即宣布完成**：Inf、精度不足、模板默认样式误判、字段运动学不一致。
10. **缓存/测试/图片使用旧状态**：FAST 污染 FINAL、跨年份同名模块、图与 Excel 不是同一最终参数、性能日志被缓存时间覆盖。

## 6. Codex 在哪些情况下能自己决定

在数学模型和题意口径已明确时，Codex 可以自主决定：

- 稳定、可验证的数值算法，如 Brent、DOP853、CN、局部/全局候选的组合；
- FAST/STANDARD/FINAL 的工程精度与缓存隔离，但最终必须用收敛证据校准；
- 数据结构、题目目录拆分、矢量化、预计算和候选粗筛的实现；
- 解析/人工测试、残差、守恒、事件前后、网格/步长收敛和性能基准；
- 官方 Excel 的只填值映射、回读、语义复算；
- 论文图和 Origin 一图一表的交付形式；
- 修复已复现的代码 BUG，并在确属通用缺陷时加 regression test。

Codex 可以提出最小显式假设继续跑比较方案，但不能静默把假设升级为最终模型。

## 7. 哪些情况必须 MODEL_CONFIRMATION_REQUIRED

1. 同一句题意允许两个以上合理数学定义，且会改变目标或约束。
2. 题面缺少物理参数，必须引入题外常数或材料/结构解释。
3. 代表点、关键点、采样比例与“完整实体”之间需要取舍。
4. 多个时间点的权重、总目标的组合方式或 max/min 口径不唯一。
5. 是否接受参数化布局、一机一目标、候选剪枝等搜索空间限制。
6. 名义最优与鲁棒/安全方案发生冲突，需要决定交付哪个。
7. 优化只能给高质量可行解，论文是否可以使用“最优”表述。
8. 外部参考与独立结果不同，差异来自模型口径而非明确程序错误。
9. 结果对未确定参数高度敏感，敏感性足以改变结论。
10. 任何会实质改变公式、目标函数、约束、边界条件或任务分配含义的选择。

## 8. 比赛当天时间表

### 前 30 分钟

- 获取官方题面、附件、模板并保存哈希；禁止先搜答案。
- 全队逐段读题，建立坐标、时间原点、单位、对象、事件、目标和输出清单。
- 立即列 `MODEL_CONFIRMATION_REQUIRED`，由建模手选择或批准并行口径。
- 检查官方 Excel 的 sheet、shape、列序、单位和说明行。
- 不写大段实现，不扩 core。

### 前 2 小时

- 完成变量表、数学模型、目标、硬约束、初边值和 I/O 约定。
- 为每条运动/物理链写解析测试或人工例。
- 先完成最简单一问或最小 baseline，打通“模型→数值→验证→输出”。
- 识别最高风险：事件、几何、守恒、拟合可辨识性、离散分配或大规模性能。
- 建立题目专用 `common.py`，不要把第一次出现的业务逻辑塞进 core。

### 第一天

- 完成 Q1 与基础子模型；形成可读结果、残差和第一版图。
- 建立 FAST/STANDARD/FINAL，验证粗筛不会改变最终事件定义。
- 写题目专用测试，覆盖方向、单位、边界、极端和失败场景。
- 对优化问题先做切片/小网格，区分不可行与合法零目标。
- 当天结束前让建模手确认所有关键模型口径。

### 第二天

- 完成中等难度各问和联合优化；固定 seed，保存候选、`nfev`、耗时和约束报告。
- 对候选做局部精修、邻域扰动、FINAL 复算和网格/表面/时间收敛。
- 生成正式 Excel 初稿并回读；图表只从 FINAL 数据生成。
- 如果性能过慢，依次减少重复、预计算、NumPy、空间筛选、缓存；此时才考虑 Numba/并行。
- 论文手开始使用 `summary.md`，不从控制台抄数字。

### 第三天

- 收口最高难度问，尤其离散＋连续组合和全局最优边界。
- 三份交付物逐字段语义复算；检查编号、排序、单位、NaN/Inf 和小数精度。
- 运行题目测试与全项目 pytest；解决跨年份导入和旧缓存。
- 做独立只读攻击审查，修复后重新跑 FINAL、Excel 和图。
- 冻结独立结果和哈希，再决定是否做官方/可靠文献 cross-check；绝不反向调参。
- 留出打包、论文引用核对和最终人工签字时间。

## 9. 正式比赛期间绝对不能省的检查

- 坐标系、时间原点、SI 单位、degree/rad 和状态向量顺序。
- 每个题外常数和模型假设的来源/签字。
- 解析解、退化例、人工几何场景或守恒基准至少一种。
- 求根残差和正确根区间；事件前、边界、事件后方向。
- 时间步长、空间网格、目标采样或 ODE 容差至少一类收敛检查。
- 硬约束独立回算；不可行不得与零目标混淆。
- 优化 seed、候选比较、成功状态、邻域扰动和 FINAL 复算。
- 对多对象的实际几何，不得只看中心点；有限线段不能写成无限直线。
- 重叠区间并集和多目标集合的正确组合。
- Excel 回读：shape、sheet、表头、顺序、单位、NaN/Inf、关键数值和物理语义。
- 图/Origin/论文数字必须来自同一最终快照。
- 全项目 pytest 和最后一轮只读反向审查。

## 10. 当前是否还值得继续扩库

**不值得在赛前继续扩充通用库。** 五道异质 A 题已经覆盖几何、ODE、PDE、拟合、积分、优化、空间筛选、连续事件、组合分配、Excel 和图；剩余主要风险是建模决策与搜索空间证明，不是缺少更多包装函数。

赛前只允许三类动作：

1. 修复能够复现的现有 core BUG，并加 regression test；
2. 做安装/环境/模板写入的烟雾测试；
3. 熟悉现有入口、knowledge 和比赛时间表。

## 最终结论

# CONDITIONALLY READY

“条件”意味着比赛时必须有建模手对模型歧义、题外物理常数和受限最优性签字，并且 Codex 必须继续执行 FINAL 复算、Excel 语义检查和独立审查。满足这些协作条件时，A_MODELING 适合直接用于 2026 高教社杯 A 题；若期待工具箱在无人确认下自动选择物理模型或证明高维组合全局最优，则尚未 READY。
