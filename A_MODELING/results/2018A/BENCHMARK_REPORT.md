## 2. 连续模型、边界与界面

四层均采用

`rho_i c_i ∂T_i/∂t = ∂/∂x(k_i ∂T_i/∂x)`。

坐标从环境侧指向皮肤侧。初温为 37 °C；外侧、人体侧分别采用 Robin 边界，`h_out` 与 `h_skin` 由实验标定。层间显式施加温度连续与热流连续。

空间离散为单元中心有限体积。相邻单元面热导按两侧半单元热阻串联：

`G = 1 / (dx_L/(2k_L) + dx_R/(2k_R))`。

该形式没有重复界面节点，并可从同一个界面热流重构左右界面温度。IV 层保留空气的密度、比热和导热率，没有简化成纯稳态热阻。

正式推进采用 Crank--Nicolson 稀疏三对角系统并复用 LU 分解。显式 Forward Euler 只用于短时交叉验证，违反稳定上限时明确报错。

## 4. 没用上的模块

- `core.geometry`、`core.spatial`：本题是一维分层传热，无空间碰撞/遮挡需求。
- `core.integration`：时间推进和阈值持续时间由离散状态与分段线性事件直接得到，无需数值积分包装器。
- `core.ode`：没有把 PDE 半离散系统硬塞进 ODE API。
- `core.optimization`：Q3 粗定位表明目标沿 IV 层厚度下降，最优点位于官方上界；此时直接验证边界比强行调用连续优化器更自然。代码保留内部点时的 bounded 分支，但本次正式路径未触发。
- `core.sensitivity`：本题需要修改材料层对象并完整复算 PDE，采用题目专用扰动表更透明。
- `core.plotting`：热力图、双轴安全图和残差图需要题目专用布局，直接使用 Matplotlib。

## 5. 实战发现的 core 缺陷

### C 类：Excel 验收未拒绝 Inf

- 问题：`core.export.write_excel_checked` 和 `verify_excel` 原来只检查 NaN，不检查正负无穷。
- 影响：优化中的不可行惩罚值可能被写入工作簿，文件可以保存却不适合 Excel/Origin，也会破坏后续图表。
- 修复：新增数值列 Inf 计数；写入前拒绝 Inf；回读结果增加 `inf_count` 并在存在 Inf 时判定失败。
- 新增回归测试：`test_excel_export_rejects_infinity`、`test_excel_verification_reports_infinity`。

### B 类：暂无通用多层 PDE API

当前 core 没有 CN、多层材料、Robin 边界和非均匀网格的统一 API。实战证明这些能力能在比赛中清晰实现，但本次只验证了一个一维传热题，尚不足以确定跨题抽象边界。因此没有新增 `core/pde.py`，也没有修改 `core.ode.py`。

## 11. 最优点邻域与敏感性

Q2 在 `17.5 mm` 时超温时长为 `329.836 s`，不可行；`17.6 mm` 为 `288.739 s`，可行。Q3 在 II 层 `19.2 mm`、IV 层 `6.4 mm` 时超温时长为 `305.516 s`，不可行；II 层 `19.3 mm` 时为 `292.395 s`，可行。事件方向正确，0.1 mm 邻域没有网格噪声反转。

Q3 的最小总厚度随 IV 层增加而持续下降，因此 IV 层最优值为官方上界 6.4 mm；这不是 bounded 优化器偶然停在边界，而是粗定位和邻域表共同支持。

敏感性结果显示，Q2 的名义最优对 ±5% 扰动较敏感。例如环境温差增加 5%、`h_skin` 减少 5% 或 IV 层导热率增加 5% 会使超温时长约束失效。因此：

- 本报告给出的厚度是严格对应题设参数和标定参数的名义最优；
- 若用于真实工程，应为环境与材料不确定性另设鲁棒裕量，不能把本题名义最优直接当生产安全厚度。

这是一项物理/决策层提醒，不是 PDE 数值不收敛。

## 16. 是否新增 core/pde.py

结论：本次不新增。

理由不是能力不足，而是抽象证据不足。当前 `common.py` 同时包含官方四层材料、两侧有效换热、厚度范围和比赛输出事件；立即上移会把 2018A 业务假设伪装成通用 PDE API。真正可复用的数值提醒已进入 knowledge，Excel 的通用缺陷已进入 core 并有回归测试。

若未来第二道独立 PDE A 题再次需要以下三项，才建议建立 `core/pde.py`：守恒型变系数一维装配、theta-method 三对角推进、统一边界/界面残差接口。
