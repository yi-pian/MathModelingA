# 碰撞与遮挡

## 用途与形式
距离小于安全阈值、线段/物体相交、观察者—目标视线被障碍物阻断。

## 推荐 API / 基本结构
球障碍用 `segment_intersects_sphere`；射线用 `ray_sphere_intersections`；粗筛用 `aabb_intersects`；同步轨迹用 `trajectory_minimum_distance`；采样真假序列转时间段用 `boolean_time_intervals`。

## 适用 / 不适用
采样判定只能发现采样点上的事件，极短碰撞/遮挡可能漏检；需要事件根求解或自适应加密。

设计参数的临界安全性必须覆盖完整过程。若参数为 `p`、有向间隙为 `c(p,t)`，应检查或求解 `G(p)=min_t c(p,t)`，不能用终点 `c(p,t_end)` 代替；内层先定位最危险时刻并连续精化，外层再对 `G(p)=0` 做可靠变号求根。最后检查 `p-eps`、`p`、`p+eps` 的可行方向以及临界时刻前后状态。

## 关键参数
明确物体是否有半径、切触是否算碰撞、目标/观察者落在障碍物内部的规则，以及时间端点包含性。

## 验证
相交、相切、分离、端点接触、零长度轨迹和高速穿越例。

## 常见错误 / A 题用途
把无限直线代替线段、忽略物体尺寸、用离散帧宣称连续安全。用于 2023/2025 类遮挡与 2024 类碰撞搜索。
