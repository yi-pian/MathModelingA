# 非线性方程组

## 用途与形式
同时满足几何、平衡或连续条件：`F(x)=0`。

## 推荐 API / 基本结构
`solve_system(F, x0)` 包装 `scipy.optimize.root`；变量顺序、单位和残差方程顺序写在文件顶部。

## 适用 / 不适用
适合维数不高、残差连续、初值有物理依据的问题。不适合把不等式约束强塞成等式；此时用受约束优化。

## 关键参数
变量尺度差异大时无量纲化或设置缩放；从多个物理可行初值复算。

## 验证
检查无穷范数残差、边界、物理范围和不同初值是否得到同一可行根。

## 常见错误 / A 题用途
变量顺序错、方程量纲不一致、求解器 success 为真但残差仍大。典型用于机构约束、稳态平衡和空间交会。
