# 空间搜索

## 用途与形式
大规模最近邻、半径搜索、碰撞候选对和局部邻域。

## 推荐 API / 基本结构
小规模先向量化广播；内存过大时分块；静态点集多次查询用 `scipy.spatial.cKDTree`；AABB 先粗筛再精确几何。

## 适用 / 不适用
KDTree 适合低维欧氏空间；高维或点集每步完全变化时建树成本可能不划算。

## 关键参数
查询半径、k、叶节点大小、是否周期边界；先估算广播矩阵内存。

## 验证
小样本与双循环穷举逐项对照；检查重复点、相同对象自身距离和边界相等情形。

候选筛选与精确判定分层时，不能只比较最终平均值。应显式验证集合包含关系 `reference_true_pairs ⊆ fast_candidate_pairs`：快速阶段允许多保留对象，但任何真实命中对的漏检都必须判为失败。射线走廊用离散查询点覆盖时，查询半径还应包含物体最大外接半径与查询点半步长，并用人工边界例和随机小场景复核。

## 常见错误 / A 题用途
只比较同索引、漏候选、把平方距离与半径比较、空间与时间索引混淆。用于密集轨迹/遮挡候选加速。
