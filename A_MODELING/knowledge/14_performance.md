# 计算性能

## 用途
在正确和已验证的实现上缩短大规模轨迹、参数扫描或优化时间。

## 优先顺序
删除重复计算 → 预计算固定参数/缓存纯函数 → NumPy 向量化 → KDTree/空间索引 → Numba → joblib/多进程。

## 推荐 API / 基本结构
先用 `benchmark` 建基线；只优化热路径。向量化前先估内存，必要时分块。固定数组可在目标函数外预计算，但目标函数不得修改全局状态。

## 适用 / 不适用
Numba 对纯数值循环可能有效，对 pandas/SciPy 调用通常帮助有限；多进程对短任务会被启动与序列化成本抵消。

## 验证
优化前后同输入结果在容差内一致；记录运行时间、硬件、数据规模和峰值内存。

## 常见错误 / A 题用途
先并行后验证、生成巨大广播数组、缓存包含可变全局依赖的函数。用于空间候选、参数扫描和重复仿真。
