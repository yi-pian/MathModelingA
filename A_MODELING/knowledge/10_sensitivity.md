# 灵敏度分析

## 用途与形式
考察参数扰动对目标和关键状态的影响，局部导数可用中心有限差分。

## 推荐 API / 基本结构
单参数表用 `one_parameter_sensitivity`；多参数局部扰动用 `multi_parameter_sensitivity`；导数用 `finite_difference_sensitivity`；无量纲比较用 `normalized_sensitivity`。

## 适用 / 不适用
±1/5/10% 反映局部稳健性，不代表全局不确定性；基准参数为 0 时百分比扰动无意义，应改绝对步长。

## 关键参数
扰动范围应符合物理可能性；每次只改目标参数，其他条件固定；记录求解器容差，避免数值噪声淹没扰动。

## 验证
正负扰动是否近似对称、步长减半导数是否稳定、非线性拐点处单独加密。

## 常见错误 / A 题用途
把相关参数独立扰动、重新优化与固定决策混为一谈、百分数用 5 而非 0.05。用于稳健性与关键参数排序。
