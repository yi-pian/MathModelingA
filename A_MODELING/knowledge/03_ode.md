# ODE

## 用途与形式
动力学、热/质传递集总模型：`y'=f(t,y,p)`。二阶 `q''=a(t,q,q')` 转成 `[q,v]'=[v,a]`。

## 推荐 API / 基本结构
`solve_ode` 基于 `solve_ivp`；平滑非刚性先用 RK45/DOP853，疑似刚性再比较 Radau/BDF。事件函数用于触地、达到阈值或遮挡切换。

## 关键参数
先定状态顺序和单位；`rtol` 控相对误差，`atol` 应匹配各状态绝对尺度；输出采样不等于内部步长。

## 刚性判断
RK 方法极慢、步长极小而解平滑，或系统含相差很大的时间尺度时考虑刚性；必须以对比结果和调用次数为证据。

## 验证
解析例、守恒量、极端参数；用 `tolerance_convergence` 收紧容差并比较关键输出。

周期受迫系统不能只看“末段曲线像稳定”。应按激励相位对齐比较相邻整周期，或将 `y(T)-y(0)=0` 写成周期射击残差；最终平均功率在完整周期上积分，并比较不同周期窗口、积分公式和 ODE 容差。耦合机械系统还应检查质量矩阵对称性（适用时）以及周期平均的“外力输入 = 辐射/摩擦耗散 + PTO 输出”能量闭合。

## 常见错误 / A 题用途
初值或状态顺序错、事件方向错、分钟当秒、解已发散仍输出。用于车辆/飞行/阻尼/温度动力过程。
