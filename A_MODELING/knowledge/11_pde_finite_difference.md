# PDE 有限差分

## 用途与形式
一维热传导 `u_t=alpha*u_xx`，二维扩散为拉普拉斯算子；只覆盖比赛可快速改造的规则网格。

## 推荐 API / 基本结构
显式 FTCS：`u_i^{n+1}=u_i^n+r(u_{i+1}^n-2u_i^n+u_{i-1}^n)`，`r=alpha*dt/dx^2<=1/2`（一维）。隐式与 Crank–Nicolson 用三对角稀疏线性系统。

## 边界条件
Dirichlet 直接赋边界值；Neumann 用单边/幽灵点离散；Robin 必须从原物理通量方程推导，不能凭经验写符号。

多层介质不要把分段 `alpha` 直接代入统一二阶差分。单元中心有限体积可把界面两侧半单元热阻串联：`G=1/(dx_L/(2k_L)+dx_R/(2k_R))`，从同一界面热流重构界面温度，并分别检查温度、热流连续残差。Robin 边界同理把半单元导热热阻与 `1/h` 串联。

## 适用 / 不适用
规则域、小中规模、扩散主导适合；复杂几何/强对流/激波不应硬套基础差分。

## 验证
稳定性条件、解析模态 `sin(pi*x)exp(-alpha*pi²t)`、`dx/dt` 同时加密、能量/最大值原理和边界残差。

多材料显式格式用各控制体的 `C_i/sum(G_face)` 取最严格稳定步长，不能只挑某一层手算 Fourier 数。厚度进入优化时固定目标 `dx` 并让各层精确铺满；候选解必须换更细网格/时间步 FINAL 复算，防止优化器利用节点数跳变。

## 常见错误 / A 题用途
漏平方 `dx²`、时间层原地覆盖、边界索引错、二维稳定性仍用一维条件。2018 A 类传热和厚度设计。
