# 参数拟合与标定

## 用途与形式
以观测 `y_i` 标定参数 `p`，通常最小化残差平方和。

## 推荐 API / 基本结构
直接函数型用 `fit_curve`；需自定义残差、权重或多输出用 `fit_least_squares`。尽可能设置物理 bounds。

## 适用 / 不适用
最小二乘假定残差定义有意义；异方差、相关误差或离群点显著时需重新定义权重/损失，不可只看 R²。

## 关键参数
初值、bounds、参数尺度、残差权重和损失函数。参数相关性高时协方差会病态。

## 验证
报告参数、RMSE、MAE、R²、残差图；训练区间外预测需单独论证。检查参数边界与残差系统偏差。

## 常见错误 / A 题用途
单位未转换、残差方向/权重错、参数超物理范围、过拟合。用于动力学/传热系数与阻尼标定。
