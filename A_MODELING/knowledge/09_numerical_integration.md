# 数值积分

## 用途与形式
功率积分得能量、速度积分得路程/位移、曲线长度、平均量和累计量。

## 推荐 API / 基本结构
函数已知用 `integrate_function(quad)`；均匀或非均匀采样用 Simpson/梯形；累计量用 `cumulative_integral`；轨迹折线长度用 `path_length`。

## 适用 / 不适用
采样数据有噪声时高阶公式不一定更好；存在跳变/尖峰时应在断点分段或加密。

## 关键参数
积分上下限、x 是否严格单调、单位乘积、采样覆盖范围。

## 验证
常数/多项式/正弦解析解；加密采样检查关键积分稳定。

## 常见错误 / A 题用途
时间单位错、把功率峰值当能量、路径长度与位移混淆、axis 错。用于能耗、总热量、路程和时间平均。
