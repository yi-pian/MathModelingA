# 二维几何

## 用途与形式
轨迹、投影、交点、点线距离、点在多边形内和旋转。

## 推荐 API / 基本结构
使用 `point_to_segment_distance`、`segments_intersect_2d`、`point_in_polygon_2d`、`rotate_2d`。点统一 `[x,y]`，角度 rad。

## 适用 / 不适用
几何判断优先向量形式和统一 `eps`；大量“水平/竖直”分支容易漏斜线与退化情况。

## 关键参数
`eps` 应相对坐标尺度合理；坐标很大但间距很小时先平移/缩放。

## 验证
平行、垂直、端点相交、共线重叠、退化线段、边界点、旋转 90°解析例。

## 常见错误 / A 题用途
x/y 颠倒、局部/全局混用、距离平方当距离、边界是否包含未说明。用于平面路径、链条、碰撞和区域判定。
