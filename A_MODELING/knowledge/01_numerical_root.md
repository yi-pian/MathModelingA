# 数值求根

## 用途与形式
求临界时刻、交点、阈值：`f(x)=0`。有可靠变号区间 `[a,b]` 时首选 Brent。

## 推荐 API / 基本结构
`solve_bracketed(f, (a,b))`；未知根区间先用 `scan_sign_changes`，多个根用 `find_all_roots`。仅在导数可靠且初值很近时考虑 Newton。

## 适用 / 不适用
连续标量函数且端点异号最可靠。偶重根不变号，扫描法可能漏掉；不连续函数的符号跳跃不等于根。

## 关键参数
先按物理量级给搜索区间，再按输出精度定 `xtol`。过度收紧容差只增加函数调用。

## 验证
检查 `converged`、`|f(root)|`、根是否在区间；与加密扫描或解析例对照。

## 常见错误 / A 题用途
度弧度混用、把极小值当根、漏偶重根、错误区间。典型用于碰撞时刻、链节位置、热传导阈值。
