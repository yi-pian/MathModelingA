# 连续优化

## 用途与形式
在边界和约束下求 `min f(x)` 或 `max f(x)`。

## 推荐 API / 基本结构
一维 `optimize_scalar`；光滑有界用 L-BFGS-B；一般约束用 SLSQP；无导数小维问题可用 Nelder-Mead；非凸且局部解风险明确时用 `optimize_global`。方向必须显式。

## 推荐流程
解析/单调性检查 → 粗网格 → 优秀区域 → 局部精化 → 高精度重算 → 邻域扰动 → 灵敏度。

## 适用 / 不适用
不要因“高级”直接上全局或元启发式；离散组合约束不能伪装成连续变量。

## 验证
检查 success、约束余量、边界、不同初值/seed、邻域值、重算目标。

## 常见错误 / A 题用途
最大最小写反、`g(x)>=0` 与 `<=0` 混淆、变量顺序错、目标函数修改全局状态。用于厚度、阻尼、轨迹和时序参数设计。
