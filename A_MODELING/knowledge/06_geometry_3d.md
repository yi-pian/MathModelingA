# 三维几何

## 用途与形式
空间轨迹、姿态旋转、线面/线球交点、投影与距离。

## 推荐 API / 基本结构
`rodrigues_matrix`、`line_plane_intersection`、`line_sphere_intersections`、点到线/段/面距离。旋转矩阵左乘列向量；默认右手系。

## 适用 / 不适用
Rodrigues 适合绕任意固定轴旋转；欧拉角多次旋转时必须声明次序，不能交换。

## 关键参数
轴向量先归一化；平行判断用点积与尺度相关容差；线、射线、线段的参数域不同。

## 验证
`R.T@R=I`、`det(R)=1`、轴向量旋转不变、切线一个交点、平行线面无唯一交点。

## 常见错误 / A 题用途
xyz 顺序、度弧度、行/列向量、旋转先后、把直线交点当射线交点。用于空间运动、视线和机构姿态。
