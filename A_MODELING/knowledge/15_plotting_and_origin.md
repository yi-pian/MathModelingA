# 论文绘图与 Origin

## 用途
Python 负责可复现计算与初图，Origin 只精修少数最终重要结果图。

## 推荐 API / 基本结构
`core.plotting` 提供时序、多序列、拟合、2D/3D 轨迹、灵敏度、收敛、热图、等高线、曲面和残差。调用者必须给轴名与单位。`save_figure` 输出 PNG 300 dpi、PDF、SVG。

## Origin 数据
用 `export_origin_table` 一图一表：首列 X，后续 Y/参数/系列；列名如 `time_s`、`temperature_C`，必要说明放 Notes。曲面/等高线应输出规则的 x-y-z 长表或明确矩阵网格。

## 适用 / 不适用
图服务于结论，不为“丰富”堆装饰；一个大图最多两子图。不要用截图替代矢量图或原始数据。

## 验证
图轴与数据列单位一致、图例系列未错位、排序正确、对数轴无非正值；导出后回读核对行列和 NaN。

## 常见错误 / A 题用途
中文字体丢失、负号乱码、轴单位遗漏、Origin 列顺序错、图上平滑而原始点未说明。适用于所有论文结果展示。
