# Outputs

This directory contains verified Origin-generated previews, PNG/PDF/SVG exports, and Origin source projects. Round one remains at the directory root. The second-round v1 deliverables are in `round2/`. The frozen v1.1 deliverables are in `v1.1/`, including `ORIGIN_SIGNATURE_SCIENTIFIC_STYLE_V1_1_FROZEN.opju`.

All four v1.1 PNG files are 2400 × 1702 px at 600 dpi. Matching PDF and SVG exports were generated from the same Origin graph pages.

Phase 2 candidate deliverables are in `phase2/`. The folder contains 11 visually reviewed figure sets in PNG/PDF/SVG plus `ORIGIN_PHASE2_STYLE_TRAINING.opju`. Single-graph PNGs are 2400 × 1702; multi-panel PNGs are 3600 × 2552. Phase 2 is pending human aesthetic review and is not frozen.

A file is not listed in a review as complete until it exists, has non-zero size, and passes visual inspection.
